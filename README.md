## 📌 Project Overview

This project presents an end-to-end **Sports Data Analytics** workflow using **R** to analyze FIFA player performance and market value. The analysis investigates how player characteristics—including age, position, overall rating, goals, assists, contract duration, and injury status—affect player valuation and transfer risk.

The project demonstrates the complete data analytics lifecycle, from data preprocessing and exploratory data analysis (EDA) to statistical hypothesis testing, predictive modeling, clustering, and business insight generation.

---

## 🎯 Objectives

* Clean and preprocess the FIFA player dataset.
* Perform Exploratory Data Analysis (EDA).
* Analyze relationships between player performance and market value.
* Compare player positions using statistical hypothesis testing.
* Build predictive models using Regression and Decision Trees.
* Segment players using K-Means Clustering.
* Generate business insights for player recruitment and valuation.

---

## 📂 Dataset

The dataset contains information for approximately **2,800 professional football players** including:

* Player Name
* Age
* Nationality
* Club
* Position
* Overall Rating
* Potential Rating
* Matches Played
* Goals
* Assists
* Minutes Played
* Market Value (Million EUR)
* Contract Years Left
* Injury Status
* Transfer Risk Level
